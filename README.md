# health-clinic

Modular static Astro website for allied-health and vet clinics. See `docs/spec.md` for the spec and `docs/plans/` for the build plan.

## Scripts

- `npm run dev` / `build` / `preview`: Astro.
- `npm test`: boundary checker, then unit tests.
- `npm run build:all`: builds the three demo sites (`SITE=fernway-au|fernway-ca|hollybank`).
- `npm run e2e`, `budget`, `photos:status`: tools added in later tasks.
